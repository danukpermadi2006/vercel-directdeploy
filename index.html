Info Keamanan & Cara Dapat Token

Aplikasi ini membutuhkan Vercel Access Token. Ikuti langkah mudah ini untuk mendapatkannya:

  1. Buka halaman pengaturan token di vercel.com/account/tokens .
  2. Klik tombol Create (Buat) di pojok kanan atas halaman.
  3. Isi kolom Token Name (contoh: "Web Deployer") dan atur masa berlakunya di bagian Expiration.
  4. Pada menu dropdown Scope, pilih Full Account agar sistem bisa membaca repository dan melakukan deploy.
  5. Klik tombol Create Token, lalu salin (copy) kode rahasia yang muncul.
  6. Tempelkan (paste) kode tersebut ke kolom Vercel Token di bawah ini.
Peringatan Keamanan: Fitur "Remember" hanya menyandikan token secara dasar (base64). Jika Anda menggunakan perangkat publik/warnet, JANGAN centang "Remember" dan pastikan untuk mengklik tombol Disconnect setelah selesai.
